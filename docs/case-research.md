# Exemplo de referência

Como referência de mercado para observabilidade em sistemas distribuídos, o projeto utiliza conceitos do OpenTelemetry, que define telemetria por sinais como métricas, logs e traces e descreve tracing distribuído como o acompanhamento do caminho de uma requisição entre serviços.

Fontes oficiais:
- OpenTelemetry Observability Primer
- OpenTelemetry Traces
- Kubernetes Documentation
- Docker Documentation
- GitHub Actions Documentation
- Terraform Documentation

O relatório deve citar o case/repositório/arquitetura concreta escolhido pelo estudante conforme a pesquisa realizada e manter a fonte primária indicada pelo professor.
